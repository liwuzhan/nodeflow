## Summary

Fix P2 issue from GPT review: Replace JSON serialization with MsgPack in SharedBufferLite for better performance and support for large data (LiDAR, cameras, numpy arrays).

## Problem Fixed

JSON serialization had limitations:
- Cannot serialize numpy.ndarray (critical for sensor data)
- Cannot serialize bytes (binary data)
- Slower performance for large datasets
- Not suitable for LiDAR/camera data as documented in README

## Solution

Implement MsgPack serialization in sdk/shared_buffer_lite.py with custom numpy encoder/decoder:

### 1. Replace JSON with MsgPack (line 14)
```python
import msgpack  # replaces json
```

### 2. Add numpy encoder (line 62-75)
```python
@staticmethod
def _encode_numpy(obj):
    if isinstance(obj, np.ndarray):
        return {
            '__ndarray__': True,
            'dtype': str(obj.dtype),
            'shape': tuple(obj.shape),
            'data': obj.tobytes()
        }
```

### 3. Add numpy decoder (line 77-87)
```python
@staticmethod
def _decode_numpy(obj):
    if isinstance(obj, dict) and obj.get('__ndarray__'):
        return np.frombuffer(obj['data'], dtype=obj['dtype']).reshape(obj['shape'])
```

### 4. Update write() and read() methods
- write(): msgpack.packb(data, default=self._encode_numpy)
- read(): msgpack.unpackb(data, object_hook=self._decode_numpy)
