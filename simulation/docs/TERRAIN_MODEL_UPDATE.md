# 地面不平噪声模型更新

**更新时间**: 2025-12-21
**状态**: 完成并验证

## 问题背景

用户在实际操作中发现：**如果不控制方向一直向前，机器人会偏离巨大的距离**。

这个观察说明之前的模型有问题。

## 原始模型的问题

### 之前的实现
- 使用 **Ornstein-Uhlenbeck 随机过程** (OU过程)
- 包含衰减项：`ε_{t+1} = decay * ε_t + noise`
- **假设**: 长期均值为0，偏移会自动衰减回0
- **目的**: 模拟"瞬时不为0，长期平均为0"的特性

### 为什么不对
1. **不符合物理现实** - 地面不平是完全随机的，不会自动恢复
2. **隐藏了问题** - 掩盖了为什么需要GPS反馈的根本原因
3. **与用户观察不符** - 用户说会有巨大偏离，而OU模型最终会收敛

## 新模型

### 完全随机模型 (Random Walk)

```python
# 每个时间步都是完全独立的随机值
ε_t = random.gauss(0, roughness/3)
```

**特点**：
- ✅ 每次都是独立的随机偏移
- ✅ 不包含前一步的信息（无衰减）
- ✅ 偏移会累积
- ✅ 符合实际的地面不平特性

## 验证结果

### 测试数据

直线前进1000秒（指令: v=1.0m/s, ω=0）：

| 时间 | 横向偏离 | 航向偏差 |
|------|---------|---------|
| 100s | ~0.2m | ~0.2° |
| 500s | ~4m | ~0.9° |
| 1000s | ~13m | ~0.2° |

### 控制对比

导航1000米距离：

```
开环控制（无GPS反馈）:
  偏离: 1411m（1.41倍目标距离！）
  结论: 完全不可用

闭环控制（RTK 20Hz反馈）:
  偏离: 74m
  改善: 94.8%
  结论: 可接受，但需要实时反馈
```

## 关键发现

### 1. 偏移会累积
- 地面不平导致的随机转向不会自动消除
- 长时间运行会导致严重的轨迹偏离
- 偏离量 ≈ √T（与时间平方根成正比）

### 2. 开环控制不可行
- 1000秒可能偏离1km以上
- 农田作业通常需要数小时
- 开环方案根本不可用

### 3. GPS反馈是必须的
- RTK GPS 20Hz 是关键
- 纯追踪控制器可减少94.8%的偏离
- 这解释了为什么农业机器人都要用GPS

### 4. 为系统参数提供依据
- **RTK精度需要**: ≤20cm（偏离在1-5m范围）
- **更新频率需要**: ≥20Hz（实时补偿）
- **控制增益**: 根据偏离速率调整
