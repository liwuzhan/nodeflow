# Web Editor 删除功能说明

## 功能概述

已实现完整的节点和连线删除功能，支持多种操作方式。

---

## 1. 删除节点

### 方式一：点击删除按钮
- **位置**：节点标题栏右上角的关闭图标（×）
- **操作**：
  1. 鼠标悬停时图标变红
  2. 点击图标
  3. 弹出确认对话框
  4. 点击"删除"确认，或"取消"放弃
- **效果**：
  - 删除节点本身
  - 自动删除所有连接到该节点的连线
  - 自动从分组中移除该节点
  - 显示成功提示

### 方式二：键盘快捷键
- **操作**：
  1. 点击选中要删除的节点（节点边框变蓝）
  2. 按 `Delete` 或 `Backspace` 键
  3. 弹出确认对话框
  4. 点击"删除"确认
- **注意**：在输入框中输入时，快捷键不会生效

---

## 2. 断开/删除连线

### 方式一：点击输入端口断开（推荐）✨
- **操作**：
  1. 找到要断开连线的**输入端口**（节点左侧）
  2. 已连接的输入端口显示为**橙色圆点**
  3. 鼠标悬停时，端口变为**红色**并显示提示"点击断开连线"
  4. 点击该端口，连线立即断开
- **交互效果**：
  - 已连接的输入端口：橙色圆点 + 橙色光晕
  - 悬停时：红色圆点 + 红色光晕 + 红色标签文字
- **优点**：
  - 直观：一个输入端口只能有一条连线
  - 快捷：无需先选中连线
  - 精确：不会误删其他连线

### 方式二：点击连线删除按钮
- **操作**：
  1. 点击要删除的连线（连线变为虚线动画，中点显示删除按钮）
  2. 点击中点的删除按钮（白色圆圈带红色 X）
  3. 连线立即删除，无需确认
- **交互效果**：
  - 鼠标悬停删除按钮时背景变为浅红色
  - X 图标变粗，颜色变为纯红色

### 方式三：键盘快捷键
- **操作**：
  1. 点击选中要删除的连线（连线变为虚线动画）
  2. 按 `Delete` 或 `Backspace` 键
  3. 连线立即删除，无需确认
  4. 显示成功提示

## 技术实现

### 删除节点流程

```
用户点击删除
  ↓
CustomNode.handleDelete()
  ↓
显示确认对话框
  ↓
用户确认
  ↓
emit('delete')
  ↓
GraphCanvas 调用 graphStore.deleteNode()
  ↓
graph.ts/deleteNode():
  - 删除相关的所有边
  - 从分组中移除节点
  - 删除节点数据
  - 清除选中状态
  ↓
显示成功消息
```

### 删除连线流程

```
用户点击删除
  ↓
CustomEdge.handleDelete()
  ↓
emit('delete')
  ↓
GraphCanvas 调用 graphStore.deleteEdge()
  ↓
graph.ts/deleteEdge():
  - 从 edges Map 中删除
  - 清除选中状态
  ↓
显示成功消息
```

### 点击输入端口断开流程

```
用户点击已连接的输入端口
  ↓
PortHandle.handleMouseDown()
  ↓
检查 position === 'left' && isConnected
  ↓
emit('disconnect')
  ↓
CustomNode.handleDisconnect(portName)
  ↓
emit('disconnectPort', portName)
  ↓
GraphCanvas.handleDisconnectPort(nodeId, portName)
  ↓
遍历 edges 找到 to_node === nodeId && to_port === portName
  ↓
graphStore.deleteEdge(edgeId)
  ↓
显示成功消息
```

### 键盘快捷键处理

```
用户按下 Delete/Backspace
  ↓
GraphCanvas.handleKeyDown()
  ↓
检查是否在输入框中
  ↓
调用 deleteSelected()
  ↓
检查当前选中的是节点还是连线
  ↓
调用对应的删除方法
```

## UI 交互细节

### 节点删除按钮
- **默认状态**：灰色图标
- **悬停状态**：红色图标
- **tooltip**：显示"删除节点"

### 已连接的输入端口
- **默认状态**：
  - 橙色圆点（#e6a23c）
  - 橙色光晕
  - 光标变为 pointer
- **悬停状态**：
  - 红色圆点（#f56c6c）
  - 红色光晕
  - 红色标签文字
- **tooltip**：显示"端口名 (类型) - 点击断开连线"

### 连线删除按钮
- **显示条件**：仅在连线被选中时显示
- **位置**：连线中点
- **默认状态**：
  - 白色圆形背景
  - 蓝色边框
  - 红色 X 图标
- **悬停状态**：
  - 浅红色背景
  - 红色边框
  - 更粗的 X 图标
- **tooltip**：显示"点击删除连线"

## 确认对话框

### 节点删除确认
```typescript
ElMessageBox.confirm(
  `确定要删除节点 "${node.package}" (${node.id}) 吗？相关的连线也会被删除。`,
  '删除节点',
  {
    confirmButtonText: '删除',
    cancelButtonText: '取消',
    type: 'warning',
  }
)
```

**原因**：
- 节点删除影响较大（包括相关连线）
- 防止误操作
- 提供清晰的影响说明

### 连线删除无确认
- 连线删除影响较小
- 可以轻松重新创建
- 提高操作效率

## 键盘快捷键

| 快捷键 | 功能 | 适用对象 |
|--------|------|---------|
| Delete | 删除选中项 | 节点或连线 |
| Backspace | 删除选中项 | 节点或连线 |

**安全机制**：
- 在 `<input>` 或 `<textarea>` 中输入时，快捷键不生效
- 避免在编辑参数时误删除节点

## 用户操作指南

### 删除节点
1. **方法一**：点击节点右上角的 × 图标 → 确认删除
2. **方法二**：选中节点（点击节点框） → 按 Delete 键 → 确认删除

### 断开连线
1. **方法一（推荐）**：点击已连接的输入端口（橙色圆点）→ 连线断开
2. **方法二**：点击连线 → 点击中点的删除按钮
3. **方法三**：点击连线 → 按 Delete 键

### 批量操作
- 当前暂不支持多选和批量删除
- 需要逐个删除节点或连线
