## 快速开始

### 启动 Web Editor

```bash
# 在项目根目录执行
./start_web_editor.sh
```

启动脚本会：
1. 自动检查并安装后端依赖（fastapi、uvicorn 等）
2. 自动检查并安装前端依赖（npm packages）
3. 同时启动后端和前端服务
4. 自动在浏览器中打开编辑器（http://localhost:5173）

按 `Ctrl+C` 可优雅关闭所有服务。

## 主要功能

### 1. 画布操作
- **缩放**：鼠标滚轮（10% ~ 300%）
- **平移**：鼠标中键拖拽
- **选择**：点击节点或连线

### 2. 节点操作
- **添加节点**：从左侧节点库拖拽到画布
- **移动节点**：拖拽节点
- **删除节点**：
  - 点击节点右上角 × 图标
  - 选中节点后按 `Delete` 或 `Backspace`

### 3. 连线操作
- **创建连线**：从输出端口（右侧）拖拽到输入端口（左侧）
- **断开连线**：
  - **推荐**：点击已连接的输入端口（橙色圆点）
  - 点击连线中点的删除按钮
  - 选中连线后按 `Delete` 或 `Backspace`

### 4. 项目管理
- **保存项目**：点击顶部「保存」按钮 → 输入项目名称 → 下载 `.nfproj.json`
- **打开项目**：点击顶部「打开」按钮 → 选择 `.nfproj.json` 文件
- **导出 YAML**：点击「导出 YAML」→ 配置参数 → 下载配置文件

### 5. 节点分组
- 在右侧面板「分组管理」选项卡中创建和管理分组
- 支持 8 种预定义颜色主题
- 可为分组添加描述信息

## 键盘快捷键

| 快捷键 | 功能 | 备注 |
|--------|------|------|
| `Delete` | 删除选中的节点或连线 | 删除节点会弹出确认对话框 |
| `Backspace` | 删除选中的节点或连线 | 同上 |
| 鼠标滚轮 | 缩放画布 | 向上放大，向下缩小 |
| 鼠标中键拖拽 | 平移画布 | - |

## 开发指南

### 添加新功能的步骤

1. **数据模型**：在 `src/models/` 中定义 TypeScript 类型
2. **状态管理**：在 `src/stores/` 中创建或更新 Pinia Store
3. **业务逻辑**：在 `src/services/` 中实现核心逻辑
4. **UI 组件**：在 `src/components/` 中创建 Vue 组件
5. **集成测试**：在父组件中导入和测试

### 调试技巧

- 使用 Vue DevTools 查看组件状态和 Store 数据
- 使用浏览器开发工具的网络标签页查看 API 请求
- 检查控制台输出的调试日志（特别是坐标计算相关）

## 技术栈

### 前端
- **框架**：Vue 3 (Composition API + TypeScript)
- **状态管理**：Pinia
- **UI 组件库**：Element Plus
- **构建工具**：Vite
- **图形渲染**：SVG（连线）+ HTML（节点）

### 后端
- **框架**：FastAPI (Python 3.12+)
- **功能**：
  - 节点 manifest 管理
  - 节点列表查询
  - CORS 支持

## 常见问题

### Q: 连线没有显示？
A: 检查以下几点：
1. 确保节点 manifest 正确加载（检查控制台）
2. 确保端口类型兼容
3. 刷新页面重试

### Q: 删除按钮看不见？
A: 已修复。确保使用最新版本，删除按钮图标应该正常显示在节点右上角。

### Q: 如何断开连线？
A: 三种方式：
1. **推荐**：直接点击已连接的输入端口（橙色圆点）
2. 点击连线 → 点击中点的删除按钮
3. 点击连线 → 按 `Delete` 键

### Q: 画布缩放后节点位置不对？
A: 这是正常的坐标转换。拖拽节点到画布时会自动应用逆变换，确保节点在正确的位置。
