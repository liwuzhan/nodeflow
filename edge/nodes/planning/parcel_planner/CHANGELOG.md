# 地块规划节点更新日志

## [2026-01-28] Web 界面增强

### 新增功能

#### 1. 增强的地块加载和显示

**地图中心自动定位**
- 选择地块时，地图自动跳转到该地块的 GPS 参考点
- 自动设置合适的缩放级别（默认 16 级）
- 平滑过渡动画

**地块自动绘制**
- 加载地块后自动在地图上绘制外边界
- 自动绘制孔洞（如果存在）
- 自动调整视图以显示完整地块（包含边距）

**视觉反馈**
- 加载地块时顶部状态栏显示"📥 加载地块: xxx..."
- 加载成功后显示"✅ 已加载: xxx"
- 删除地块时显示"🗑️ 已删除: xxx"

#### 2. 增强的地块列表

**更多信息显示**
- 地块名称和描述
- 更新时间（格式：月/日 时:分）
- 当前激活地块高亮显示（紫色背景）

**新增操作按钮**
- 👁️ 查看按钮：点击加载并显示地块
- 🗑️ 删除按钮：删除地块（带确认提示）

**列表样式优化**
- 更现代化的卡片式设计
- 悬停高亮效果
- 按钮图标化，节省空间

#### 3. 删除地块功能

**前端功能**
- 点击删除按钮弹出确认对话框
- 删除后自动刷新地块列表
- 如果删除的是当前编辑的地块，自动清除编辑器

**后端支持**
- 新增 WebSocket 事件 `delete_parcel`
- 删除成功后广播 `parcel_deleted` 事件
- 自动更新地块列表

### 使用方法

#### 查看已保存的地块

1. 打开 Web 界面 (http://localhost:8081)
2. 查看右侧"📂 已保存的地块"列表
3. 点击任意地块条目

**结果**：
- 地图自动跳转到地块位置
- 显示参考点（橙色标记）
- 绘制地块边界（蓝色）
- 绘制孔洞（红色，如果有）
- 视图自动调整为最佳视角

#### 删除地块

1. 在地块列表中找到要删除的地块
2. 点击该地块右侧的 🗑️ 删除按钮
3. 在弹出的确认对话框中点击"确定"

**结果**：
- 地块从列表中移除
- 对应的 JSON 文件被删除
- 如果是当前编辑的地块，编辑器自动清空

### 已知限制

1. **地块切换限制**
   - Web 界面只用于创建和查看地块
   - 节点运行时发送的地块由 `parcel_name` 参数控制
   - 需要通过修改节点参数来切换运行时地块

2. **删除限制**
   - 删除操作不可恢复
   - 没有回收站功能
   - 建议删除前先备份重要地块
