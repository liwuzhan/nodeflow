# 快速开始指南

## 安装

### 1. 克隆项目

```bash
git clone <repository_url>
cd 节点化
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

或安装为可编辑包：

```bash
pip install -e .
```

## 运行示例

### 1. 查看示例配置

示例配置位于 `examples/runtime.yaml`：

```yaml
graph_id: rtk_controller_demo
graph_version: 1
node_hub_path: ./node-hub

nodes:
  - id: rtk_main
    package: rtk
    params:
      device: "/dev/ttyUSB0"
      baudrate: 115200
      update_rate_hz: 10.0
      simulation_mode: true

  - id: controller_main
    package: controller
    params:
      vehicle_type: "tracked"
      max_speed: 2.0
      target_heading: 90.0
      enable_control: true

edges:
  - from: rtk_main.gps_fix
    to: controller_main.gps_fix
    type: gps.fix

restart_policy:
  max_retries: 3
  backoff_ms: 500
```

### 2. 启动框架

```bash
python3 -m runtime.main examples/runtime.yaml
```

或者使用完整路径：

```bash
python3 runtime/main.py examples/runtime.yaml
```

## 开发自己的节点

### 1. 创建节点目录

```bash
mkdir -p node-hub/my_node
```

### 2. 编写节点说明书 (node.yaml)

```yaml
name: my_node
version: 0.1.0
description: 我的第一个节点

entrypoints:
  linux:
    kind: python
    cmd: ["python3", "run.py"]

ports:
  inputs:
    - name: input1
      type: data.type
  outputs:
    - name: output1
      type: data.type

params:
  param1:
    type: string
    required: true
  param2:
    type: int
    default: 100
```

### 3. 编写节点脚本 (run.py)

```python
#!/usr/bin/env python3
import sys
from pathlib import Path

# 添加SDK路径
sys.path.insert(0, str(Path(__file__).parent.parent.parent))

from sdk.nodeflow_sdk import NodeFlowSDK

def main():
    with NodeFlowSDK(log_level="INFO") as sdk:
        sdk.logger.info("My Node started")

        # 获取参数
        param1 = sdk.require_param('param1')
        param2 = sdk.get_param('param2', 100)

        # 创建端口
        input_port = sdk.create_input_port('input1')
        output_port = sdk.create_output_port('output1')

        # 主循环
        try:
            while True:
                # 接收数据
                data = input_port.recv_latest()

                if data:
                    # 处理数据
                    processed = process_data(data, param1, param2)

                    # 发送数据
                    output_port.send(processed)

        except KeyboardInterrupt:
            sdk.logger.info("Shutting down...")

if __name__ == '__main__':
    main()
```

### 4. 在运行配置中使用

```yaml
nodes:
  - id: my_node_instance
    package: my_node
    params:
      param1: "value"
      param2: 200

edges:
  - from: some_node.output
    to: my_node_instance.input1
```

## 常见问题

### 节点启动失败

检查：
1. node.yaml 中的 entrypoint 路径是否正确
2. 节点脚本是否有执行权限（`chmod +x run.py`）
3. 节点依赖的库是否已安装

### Socket连接失败

检查：
1. 输入/输出端口名称是否与 node.yaml 一致
2. edges 配置是否正确
3. `/tmp/nodeflow_sockets` 目录权限

### 循环依赖

检查 edges 配置，确保没有形成环路：
- A → B → C → A （错误）
- A → B → C （正确）
