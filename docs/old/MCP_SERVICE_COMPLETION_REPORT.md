## 🎯 项目目标

为 NodeFlow 项目实现一个完整的 MCP 服务，使 AI（如 Claude）能够：
- 查询和获取节点库信息
- 验证和修改运行时配置
- 启动和停止运行时
- 监控运行时状态
- 读取和分析节点日志

**成功指标**: 实现 7 个 MCP 工具，通过完整的集成测试


## 📋 错误处理

### 标准化错误类型

```python
{
  "success": false,
  "error": {
    "type": "ERROR_TYPE",
    "message": "详细错误信息"
  },
  "timestamp": 1234567890.0
}
```

**定义的 9 种错误类型**:
1. `NODE_NOT_FOUND` - 节点包不存在
2. `NODE_HUB_ERROR` - 节点库路径问题
3. `FILE_NOT_FOUND` - 文件不存在
4. `INVALID_INPUT` - 参数验证失败
5. `NODE_INFO_ERROR` - 节点信息查询异常
6. `VALIDATION_ERROR` - YAML 验证异常
7. `EDIT_ERROR` - YAML 编辑异常
8. `TOOL_ERROR` - 工具执行异常
9. `UNKNOWN_TOOL` - 工具不存在
